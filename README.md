# MUS'HAFI (مصحفي)

تطبيق قرآن كريم يعمل دون إنترنت لنظام Android. هذا المستودع في **المرحلة الثانية** (هيكل المشروع والشاشة الرئيسية).

## الحالة الحالية
- هيكل مشروع Gradle (AGP 8.5.2، minSdk 29، targetSdk 35).
- شاشة رئيسية بالألوان الزمردية والذهبية وتخطيط RTL، مبنية على الصورة المرجعية.
- الأزرار معطّلة حتى تُنفَّذ مراحلها، ولا يوجد أي زر يعمل بوظيفة وهمية.
- **لم يُختبر البناء** لأن بيئة التطوير الحالية لا تحتوي Android SDK أو Gradle.

## النص القرآني
- `data/quran-simple.txt`: نسخة Tanzil البسيطة (v1.1) بدون أي تعديل.
- حالة التحقق: الفحص البنيوي ناجح (6236 آية، 114 سورة). **المقارنة الحرفية مع المرجع الرسمي لم تكتمل بعد.** انظر `docs/quran-verification-report.md`.
- المحتوى مرخّص بموجب Creative Commons Attribution 3.0 (Tanzil Project). يجب الإبقاء على كتلة الحقوق في الملف وذكر المصدر في التطبيق.

## البناء
1. افتح المجلد في Android Studio.
2. اترك Android Studio يُنشئ Gradle Wrapper ويُنزّل الاعتماديات.
3. شغّل التطبيق على جهاز بنظام Android 10 أو أحدث.

## المراحل القادمة
3. استيراد النص القرآني مع التحقق، والقارئ.
4. الفهرس والتنقل والعلامات المرجعية والبحث.
5. مكتبة القراء ومشغل Media3.
6. مدير التحميلات وتشغيل الصوت دون إنترنت.
7. مراجعة بصرية كاملة.
8. الاختبارات وبناء الإصدار.

## ملاحظات
- اسم الحزمة `com.csm.mushafi` افتراض مؤقت، يمكن تغييره قبل النشر.
- لم يُضف أي مفتاح API أو بيانات اعتماد إلى المستودع.
