# مسودة نموذج Data safety (Google Play)

**مسودة للتعبئة اليدوية في Play Console، لم تُرسل بعد.** راجع كل سؤال عند الإرسال.

| السؤال | الجواب المقترح | ملاحظة |
|---|---|---|
| هل يجمع التطبيق بيانات مستخدم؟ | لا | لا حساب ولا تحليل ولا إعلانات |
| هل يشارك التطبيق بيانات مع أطراف ثالثة؟ | لا | الاتصال بخوادم MP3Quran لا يحمل بيانات شخصية من التطبيق |
| هل البيانات مشفّرة أثناء النقل؟ | نعم | جميع الروابط https |
| هل يمكن للمستخدم طلب حذف بياناته؟ | نعم | بياناته على جهازه؛ الحذف من الإعدادات أو إزالة التطبيق |
| هل التطبيق مخصص للأطفال؟ | لا | |

**ملاحظة:** إذا أُضيفت لاحقاً أدوات تحليل أو تعطّل (crash reporting) أو إعلانات، يجب تحديث هذا النموذج.
