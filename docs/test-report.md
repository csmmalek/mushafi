# تقرير الاختبار — المرحلة الثامنة

**التاريخ:** 2026-11-23 · **الفرع:** stage-8 · **الإصدار:** 0.6.0-stage8 (versionCode 3)

## ما شُغّل فعلاً (في GitHub Actions)
| الاختبار | الوسيلة | النتيجة |
|---|---|---|
| اختبارات الوحدة (Quran verifier، ArabicNormalizer، KhatmahPlanner، ReciterCatalogue، Mp3Check) | `testDebugUnitTest` في "Build and test" | نجح |
| بناء APK تصحيح | `assembleDebug` | نجح |
| اختبارات الواجهة على Android 10 (API 29) | `connectedDebugAndroidTest` في "Emulator tests" | نجح (NetworkPlaybackTest، DownloadAndOfflinePlaybackTest) |

## ما لم يُختبر
- **شاشة الإعدادات:** لم يُكتب لها اختبار واجهة، ولم تُفحص على جهاز. بنيها نجح كتجميع فقط.
- **حذف الملفات الصوتية من الإعدادات:** لم يُختبر.
- **الوضع دون إنترنت الحقيقي (airplane mode):** لم يتحقق (انظر تقرير المرحلة السادسة).
- **الثيمات الفاتحة والداكنة، واتجاه RTL، والأحجام الصغيرة:** لم تُفحص بصرياً.
- **الإشعارات، تركيز الصوت، سماعات الرأس:** لم تُختبر.
- **Android 14 والأحدث، وAndroid 16 (API 36):** لم يُشغَّل التطبيق على أي منها. الحد الأدنى للبناء هو API 36 كهدف، لكن الاختبار كان على API 29 فقط.
- **Play Console:** لم يُرفع أي شيء.

## ملاحظة عن targetSdk
رُفع `compileSdk` و`targetSdk` إلى 36 بعد التحقق من صفحة Google Play: التطبيقات الجديدة والتحديثات تحتاج API 36 ابتداءً من 31 أغسطس 2026. تم تثبيت منصة API 36 وأدوات البناء 36.0.0 في CI، ونجح البناء.
